# Formatting Rules

These are the human quirks that make posts feel authored, not generated.

---

## Bullet Points

Use `→` or `*` as-is for bullet points. Not `-`. Not `•`.

```
→ First point
→ Second point
→ Third point
```

or

```
* First point
* Second point
* Third point
```

---

## Numbered Lists

Use `1/` `2/` `3/` format — not `1.` `2.` `3.`

```
1/ First item
2/ Second item
3/ Third item
```

---

## The Em Dash Close

Use `—` at the end of the post before the final CTA, reflection, or note.

```
[rest of post]

— If you're doing this wrong, DM me. I'll take a look for free.
```

or

```
— Most people never figure this out until year 3. You don't have to wait that long.
```

---

## ALL CAPS for Emphasis

Use sparingly — maximum once per post, ideally zero.

Only for genuine emphasis where the word needs weight:
- "I NEVER thought we'd try this strategy."
- "This one thing ALONE changed our close rate."
- "We were WRONG about everything."

Do not use for decoration. Do not use more than once.

---

## Line Breaks

LinkedIn collapses long paragraphs. Use white space deliberately.

Each thought gets its own line or short paragraph. Max 3-4 lines before a break.

The hook always stands alone — one or two lines, then a break before the post body.

---

## Formatting Don'ts

- Don't use headers (`##`) in posts — this is LinkedIn, not a document
- Don't bold random phrases mid-sentence for emphasis
- Don't use `---` dividers inside posts
- Don't use emoji as decoration (only if it matches the client's natural voice)
- Don't end every bullet with a period — either all with or all without, be consistent
